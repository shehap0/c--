# ICPC Problem Solutions

A personal archive of solutions to competitive programming problems from
**Codeforces**, originally created for the **ICPC Assiut University** (Egypt)
training contests. Most solutions are written in **C++**, with a few early
problems also solved in **Python**.

> This is an old learning repo. Some solutions are clean, some are messy, and
> some are straight up wrong — I kept them all on purpose to track how I
> learned. I'm no genius, just someone who kept showing up.

## File Naming Conventions

The filenames are a little chaotic on purpose — they were my own way of
tagging things while practicing:

- `A_ProblemName.cpp` — the letter prefix matches the problem letter on the
  Codeforces contest page (A, B, C, ...).
- `..._WRONG.cpp` — submission that failed; kept as a reminder.
- `..._TIMEEXCEEDED.cpp` — correct logic but too slow.
- `..._GPT.cpp` / `{CHATGPT}.cpp` — a version written or fixed with ChatGPT
  for comparison.
- `..._easyway.cpp` / `..._hardway.cpp` — two different approaches to the
  same problem.
